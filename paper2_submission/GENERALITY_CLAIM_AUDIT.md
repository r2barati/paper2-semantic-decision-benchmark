# Generality claim audit

The manuscript's defensible scope is controlled sequential operational
environments with multiple disruption types and a multi-echelon replication.
The terms “general,” “broadly,” and “robust” must be read as framework-level
or within-study claims, not universal deployment claims.

Allowed: a reusable evaluation pattern for studying semantic information
before a fixed sequential controller.

Not allowed: claims of universal interpreter superiority, production supply-chain
validation, or general LLM capability. “Real” should refer only to frozen
real-demand traces/windows where that wording is exact; the current manuscript
uses the safer controlled-environment language.
