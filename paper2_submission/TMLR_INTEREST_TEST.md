# TMLR interest test

An ML researcher learns that semantic interpretation should not be evaluated only by classification accuracy or language-model scores when its output is a belief consumed by a sequential controller. In the frozen study, probability calibration, asymmetric action consequences, controller capability, and operational dynamics jointly determine realized value: calibration raises value despite lower accuracy in one controlled comparison, held-out semantic signals retain positive value in the multi-echelon transfer, and the perfect semantic reference can be harmful when the controller/environment pairing is mismatched. The lesson is a reproducible evaluation protocol and a set of bounded mechanisms, not universal superiority of an interpreter or a new calibration theorem.
