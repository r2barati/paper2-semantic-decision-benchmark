# Sem2Act v5 paper snapshot

This directory is the isolated manuscript surface for sem2act-v5.

manuscript_lncs/ starts as a byte-preserved copy of the v4 LNCS source. It
must not be edited to describe v5 evidence until the frozen v5 result manifest
exists. Every v5 paper edit should cite a v5 result, protocol, or artifact
manifest and leave versions/sem2act-v4/paper/ unchanged.

The v5 release gate is:

1. accepted lockbox retrieval and consumer manifests;
2. frozen v5 belief assembly, simulation, and RESULT_MANIFEST.json;
3. claim-to-result audit;
4. A4/LNCS compile and twelve-content-page check;
5. anonymous source and artifact scan.
